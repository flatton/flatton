## 💼 Selected Projects — 案件・開発実績

- プライバシーファーストAI：産業特化LLMの開発
  - 産業特化LLMの開発リードとして、継続事前学習・教師ありファインチューニング（SFT）・強化学習（RL）・評価まで、開発全般を担当。
- GENIAC第3期：エージェント向け基盤モデルの開発
  - 日本語・ロングコンテキスト性能の強化に向け、Qwen3-14B、gpt-oss-20b / 120bの継続事前学習を担当。
  - ロングコンテキスト性能を評価する[ベンチマーク](https://github.com/abeja-inc/longcontext-evaluation)を構築。
  - ロングコンテキスト性能の強化に向けたSFTデータの合成を担当。
- 医療LLMの開発に向けた学習データ整備
  - 大規模な医療データの前処理、および学習に用いる医学文献の収集を担当。
- LLMのモデルマージ・Fine-tuningに関する技術検証
- 固有表現抽出モデルの誤り検出
  - テキストへのタグ付けシステム内で用いられる固有表現抽出（NER）モデルについて、運用後の継続的な改良のために、抽出誤りを自動検出する技術を開発。
- 業務マニュアルの検索・改訂支援システムの開発
  - マニュアル検索・ドキュメント解析を通じて、改訂が必要な箇所の特定と修正内容の提案を支援するシステムを開発。
- 施設関連データの可視化・分析
  - 施設の利用ログや関連データを用いた可視化ダッシュボードの開発、およびデータ分析を担当。
